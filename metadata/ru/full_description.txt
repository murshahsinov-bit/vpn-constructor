<p>ShieldVPN — бесплатный VPN-клиент для Android на открытом ядре Xray. Всё управление сводится к одной большой кнопке «Подключиться»: приложение замеряет пинг всех серверов из подписки, выбирает самый быстрый доступный и только после этого поднимает туннель. Ни рекламы, ни аналитики, ни регистрации на сайте.</p><p><b>Что внутри</b></p><ul><li><b>Умный автовыбор</b> — при запуске приложение пингует весь список серверов и подключается к лучшему. В списке серверов видны флаг страны, название узла и пинг в миллисекундах с цветовой индикацией от зелёного до красного.</li><li><b>Локальный обход DPI для YouTube</b> — встроенный ByeDPI (ciadpi) слушает 127.0.0.1:1080, и только домены YouTube (youtube.com, youtu.be, googlevideo.com, ytimg.com и другие) идут через него. Остальной трафик продолжает идти через зашифрованный туннель VLESS/Reality, а системный VPN обход не перехватывает.</li><li><b>Актуальные подписки</b> — приложение поставляется с подпиской, которая постоянно пересобирается из публичных источников VLESS/Reality, и её можно обновить прямо с главного экрана.</li><li><b>Вход в аккаунт</b> — доступ к VPN открывается после входа через Google или по e-mail, поэтому токен подписки можно перенести на другое устройство. В сборках без ключей Firebase тот же экран работает локально и хранит только хеш пароля на устройстве.</li><li><b>Протоколы</b> — VLESS с Reality, XHTTP, TCP+TLS/Vision, VMess, Trojan, Shadowsocks, SOCKS, WireGuard и Hysteria2, импорт из стандартных share-ссылок и подписок.</li></ul><p><b>Как это работает</b></p><p>ShieldVPN запускает Xray как локальный VPN-сервис. Профили берутся из share-ссылок, QR-кодов или подписок, правила маршрутизации редактируются на экране дополнительных настроек. Ядро Xray, гео-базы и бинарник ByeDPI — свободное ПО; при сборке проекта они скачиваются скриптом <i>scripts/fetch-libs.sh</i>, поэтому в репозитории нет готовых бинарников.</p><p><b>Приватность</b></p><p>В приложении нет рекламных и трекинговых SDK. Единственные сетевые адреса, к которым обращается ShieldVPN, — URL подписки, серверы из неё и, если сборка сделана с ключами Firebase, Firebase Auth/Firestore для синхронизации аккаунта и токена подписки. Сборки без этих ключей вообще не обращаются к бэкенду Google.</p><p><b>Свободное ПО</b></p><p>ShieldVPN — форк v2rayNG и распространяется по лицензии GNU General Public License v3.0. Исходный код, инструкция по сборке и трекер задач: <a href="https://github.com/murshahsinov-bit/vpn-constructor">github.com/murshahsinov-bit/vpn-constructor</a>. VPN-клиент — это средство безопасности, поэтому код можно прочитать, проверить и собрать самостоятельно.</p>
