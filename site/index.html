Умный автовыбор

При запуске приложение пингует весь список серверов и подключается к самому быстрому. Нужен другой — открой список: флаг, название и пинг в миллисекундах видны сразу.

Обход DPI для YouTube

Встроенный ByeDPI работает локально на 127.0.0.1:1080. Только трафик YouTube идёт через него, остальное — через защищённый VLESS-туннель. Системный VPN не перехватывается.

Бесплатно

Никаких подписок и пробных периодов. Актуальные конфиги обновляются автоматически, а приложение собирается из открытого исходного кода.

Как установить

  1. 1
    Скачайте APK

    Кнопка выше ведёт на последний релиз в GitHub Releases. Для большинства телефонов берите файл ShieldVPN_1.0.0_arm64-v8a.apk, для старых 32-битных устройств — …_armeabi-v7a.apk.

  2. 2
    Разрешите установку

    Android спросит про «Установку из неизвестных источников» — разрешите её для браузера или файлового менеджера.

  3. 3
    Откройте ShieldVPN

    Войдите через Google или по e-mail, нажмите «Подключиться» и разрешите создание VPN-подключения.

Из России? Если GitHub открывается с трудом, скачайте APK через зеркало или попросите файл у того, у кого он уже есть: подпись сборки проверяется Android автоматически.
